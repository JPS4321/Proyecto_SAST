Un CRM pequeño para practicar software seguro.

Secure CRM es un sistema de tickets intencionalmente vulnerable. Sirve como campo de práctica, para que puedas leer el código, escanearlo y corregirlo simulando un proyecto real.

El proyecto

Qué es Secure CRM

Un monorepo con dos aplicaciones. La web es Next.js. La API es Express con TypeScript y guarda los datos en SQLite. Comparten tipos en un paquete común.

Qué puedes hacer en la app

Iniciar sesión con JWT, ver un tablero, y crear, buscar, editar y eliminar tickets. Un administrador también gestiona usuarios y roles. La rama principal se mantiene vulnerable a propósito: las correcciones van en tu propia rama.

Para qué sirve en el curso

Es un blanco local para DAST, SAST, análisis de dependencias y pruebas. También puedes ignorarlo y aplicar las mismas guías a cualquier otro proyecto que corra en tu máquina.

Arranque

Cómo levantarlo

Necesitas Node 20 o superior y pnpm, o Docker. Cuando termine, abre la web en el puerto 3000.

Opción A · Node + pnpm

pnpm install
pnpm seed
pnpm dev
# Web  → http://localhost:3000
# API  → http://localhost:4000

Opción B · Docker

docker compose up --build
# Web  → http://localhost:3000
# API  → http://localhost:4000

pnpm seed borra y vuelve a crear usuarios y tickets. Si el puerto 4000 está ocupado, cambia API_PORT y NEXT_PUBLIC_API_URL juntos. El ejemplo está en .env.example.

Antes de escanear

  • Analiza y prueba únicamente tu instancia local o un entorno que tengas autorizado.
  • No despliegues Secure CRM en producción ni apuntes las herramientas a sistemas de terceros.
  • No publiques tokens, claves ni contraseñas en el repositorio, en capturas ni en el reporte.
  • El mapa de fallos y las correcciones de referencia no forman parte del material del estudiante.
La rama principal sigue vulnerable. Tus correcciones van en tu rama y en el pull request.
